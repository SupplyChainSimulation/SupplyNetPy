# SupplyNetPy Documentation

SupplyNetPy is a Python library specifically designed and developed to model and simulate different supply chain problems with ease. It provides configurable components such as raw-material suppliers, manufacturers, distributors, retailers and customer demands for creating arbitrary supply chain networks, along with configurable replenishment policies and supplier-selection policies. With SupplyNetPy, we can quickly assemble a supply chain, specify demand and supply behaviors, and run simulations to evaluate performance metrics such as orders fulfilled, shortages, costs and profit, for each site, each link and the whole network.
